1Why objects exist

Before any new code: the problem that objects were invented to solve.

Imagine Happy Paws keeps every fact on its own sticky note. One note says "Rex". Another says "3". Another says "Bella". Another says "5". Notes all over the wall. Which age belongs to which name? Nothing joins them together.

Now imagine one folder per animal. Rex's folder holds Rex's name and Rex's age. You can pick it up, hand it to someone, or put it on a shelf with the others, as one thing. An object is that folder.

Here is the sticky-note way, using only what you know from the warm-up:

It does not grow100 animals means 200 variables and 100 nearly identical print lines.

This is where you are heading. Do not worry about how it works yet, just notice how it reads:

rex is one thing. It carries its own name and its own age, and you ask it for them. That is the whole idea.

Object-oriented programming (OOP) means building a program out of objects. Each object is one thing (one dog, one cat, one shelter) that carries its own facts and its own actions.

What it knowsIts facts: a name, an age. In code these are variables that live inside the object.
What it can doIts actions: bark, have a birthday, tell you its name. In code these are functions that live inside the object. They are called methods.

What is an object, in one sentence?

One thing in your program that bundles its own data (what it knows) with its own actions (what it can do). Rex is an object: he knows his name and age, and he can bark.

Why not just use separate variables like name1 and age1?

Nothing ties the pieces together, the number of variables explodes as you add animals, and there is no single "Rex" you can pass to a function or put in an array.

What does OOP stand for, and what does it mean?

Object-oriented programming. You build the program out of objects, where each object holds its own data and the functions that work on that data.

An object has two kinds of things inside it. What are they?

Data (variables: what it knows) and behaviour (methods: what it can do).

A constructor is a special method with the same name as the class and no return type. It runs automatically when an object is created, and its job is to give the object its starting values.

Python's constructor is def __init__(self, name, age):. In C++ it is named after the class instead.

  1. Giving the constructor a return type
    void Dog(string n, int a) { ... }
    Dog(string n, int a) { ... }

    A constructor has nothing in front of its name. With void there, the compiler rejects it.

  2. Filling the wrong box
    n = name;
    name = n;

    The thing on the left gets filled. You want to fill the object's name, so it goes on the left.

  3. Same name on both sides
    Dog(string name, int age) { name = name; }
    Dog(string n, int a) { name = n; }

    name = name copies the incoming value onto itself, and the object's box stays empty. Use different names, or this->name = name;.

  4. Writing new out of habit
    Dog rex = new Dog("Rex", 3);

    Dog stray();
    Dog stray;

    With empty brackets C++ thinks you are announcing a function called stray. Leave them off.

  6. Arguments in the wrong order
    Dog rex(3, "Rex");
    Dog rex("Rex", 3);

    The order must match the constructor: (string n, int a) means text first, then the number.

What is the difference between the stack and the heap?

The stack holds local variables and is cleaned up automatically when the function ends. It is fast but small. The heap holds objects made with new. They stay until you delete them, so they can live longer than the function that made them, and the heap is much bigger.

A special method named ~ plus the class name, such as ~Dog(). It runs automatically when the object is destroyed, and it is used for clean-up.

Say it: "oh of log n". Nearly as good.

O(n) · linearNo numbers, no book. Check every kennel until you find her. Twice the animals, twice the walking.

Say it: "oh of n". Fine for small groups.

What is a data structure?

A way of organising a group of values so that the things you need to do with them are easy and fast. Arrays, linked lists, stacks, queues, dictionaries and sets are the common ones.

What does Big-O tell you?

How the amount of work grows as the amount of data grows. It counts steps, not seconds.

What do O(1) and O(n) mean?

O(1) is constant time: the same number of steps however much data there is. O(n) is linear time: the steps grow in line with the data, so twice the data is twice the work.

What is the time complexity of getting an item from an array by its index?

O(1). The items sit side by side, so the computer goes straight to it.

What is the time complexity of searching an unsorted array for a value?

O(n). In the worst case you check every item.

What is the difference between an array and a vector?

An array has a fixed size. A vector can grow and shrink, and it knows its own size.

What is the difference between an array and a linked list?

An array stores items side by side, so access by index is O(1), but inserting in the middle is O(n) because items have to shift. A linked list stores items anywhere, each pointing to the next, so reaching an item is O(n), but inserting or removing at a known place is O(1).

What is the difference between a stack and a queue?

A stack is last in, first out: you add and remove at the same end, like a pile of bowls. A queue is first in, first out: you add at the back and remove from the front, like a waiting line.

What is the difference between a dictionary and a set?

A dictionary stores key and value pairs, and you look up a value by its key. A set stores keys only, with no duplicates, and you ask whether something is in it. Both use hashing, so both are O(1) on average.

Why is a dictionary lookup O(1)?

A hash function turns the key into a position, so the dictionary goes straight to it instead of searching.

What is a collision?

When two different keys hash to the same position. The table then has to keep both there and check among them.

What are the C++ names for a dictionary and a set?

unordered_map and unordered_set. There are also map and set, which keep keys sorted and are O(log n).

What is the time complexity of a loop inside a loop over the same data?

O(n²).

You need to check whether a name has been seen before, thousands of times. Which structure?

A set. Checking is O(1) on average, where searching a vector each time would be O(n).

Classes and objects

What is a class?

A template that describes what data and what actions a kind of thing has. It is like a blank form. On its own it holds no data.

What is an object?

One real thing made from a class, with its own values. If Dog is the class, then Rex, aged 3, is an object.

What is the difference between a class and an object?

The class is the template and the object is one thing built from it. You write the class once and can make many objects from it, each with different values.

What is a method?

A function that belongs to a class. It is called on an object with a dot, like rex.getName(), and it can use that object's variables.

What is the difference between a function and a method?

A function stands alone. A method lives inside a class and is called on an object.

Constructors and access

What is a constructor?

A special method that runs automatically when an object is created. It has the same name as the class and no return type, and it is used to give the variables their first values.

What is a default constructor?

A constructor that takes no inputs. If you write no constructor at all, C++ gives you an empty one.

What is a destructor?

A special method, ~ plus the class name, that runs automatically when the object is destroyed. It is used to clean up.

What is the difference between private, protected and public?

Private members can only be used inside the class. Protected members can be used inside the class and its children. Public members can be used from anywhere.

Why make variables private?

So that nothing outside the class can set them to bad values. The class controls every change through its own methods. This is encapsulation.

What are getters and setters?

Public methods that read or change a private variable. A setter can check the new value before it accepts it.

Static

What does static mean?

It belongs to the class itself and not to any one object. There is one copy, shared by every object of that class.

What is the difference between a static and a non-static variable?

Every object has its own copy of a non-static variable, like each dog's name. A static variable has one copy shared by all, like a count of how many dogs exist.

What is the difference between a static and a non-static method?

A non-static method is called on an object and can use that object's variables. A static method is called on the class, needs no object, and can only use static members.

Give an example of when you would use static.

Counting how many objects of a class have been created, or a value every object shares, such as the shelter's name.

Inheritance and polymorphism

What is inheritance?

A child class gets the variables and methods of a parent class and can add or replace some. It models "is a": a Dog is an Animal.

What is polymorphism?

The same method call behaving differently depending on the real object. Calling sound() through an Animal* gives Woof for a dog and Meow for a cat.

What does virtual do?

It tells C++ to choose the method at run time from the real object, not from the type of the pointer. Without it, the parent's version runs.

What is the difference between overloading and overriding?

Overloading is several methods with the same name and different inputs, in the same class. Overriding is a child class replacing a virtual method of its parent, with the same name and the same inputs.

What is the difference between inheritance and composition?

Inheritance is "is a": a Dog is an Animal. Composition is "has a": a Shelter has animals, kept as member variables.

Abstract class and interface

What is an abstract class?

A class that cannot be used to make objects, because it has at least one pure virtual method. It exists to be a parent. It can still hold variables and finished methods that children share.

What is a pure virtual method?

A method with no body, written virtual string sound() = 0;. Every child must write it, or the child is abstract too.

What is an interface?

A list of methods that a class promises to have, with no code and no data. In C++ it is written as a class containing only pure virtual methods.

What is the difference between an abstract class and an interface?

An abstract class can have variables and finished methods as well as blanks, and it describes what something is. An interface has only blanks and describes what something can do. A class has one main parent but can implement many interfaces.

When would you choose an interface over an abstract class?

When unrelated classes need to share an ability and there is no shared code or data. A Dog and a Parrot can both be Trainable without anything else in common.

Memory and data

What is the difference between the stack and the heap?

The stack holds local variables and is cleaned up automatically when the function ends. The heap holds objects made with new, which stay until you delete them. The stack is fast and small. The heap is bigger and you manage it yourself.

What is a memory leak?

Heap memory that was never deleted and can no longer be reached, so it is wasted for the rest of the program.

What is a pointer?

A variable that holds the address of something else. You follow it with an arrow, as in bella->getName().

What is the time complexity of reaching an item in an array by index, and of searching for a value?

O(1) by index. O(n) to search an unsorted array.

What is the difference between an array and a linked list?

An array keeps items side by side, so access by index is O(1) but inserting in the middle is O(n). A linked list chains items with pointers, so reaching one is O(n) but inserting at a known place is O(1).

What is the difference between a stack and a queue?

A stack is last in, first out. A queue is first in, first out. Adding and removing are O(1) in both.

What is the difference between a dictionary and a set?

A dictionary stores key and value pairs, and you look up a value by its key. A set stores unique keys only, and you ask whether something is in it. Both use hashing, so both are O(1) on average.

What are the four pillars of OOP?

Encapsulation, abstraction, inheritance and polymorphism.

4When your mind goes blank

It happens to everyone. What matters is what you do next.

Say the five stepsClass. Constructor. Getters. Objects in an array. Loop and print. Saying them out loud gives you the next thing to type.
Type the skeleton firstIncludes, an empty class with private: and public:, an empty main. Now you are filling in gaps, not facing a blank page.
Talk while you type"I am making the variables private, so I need getters." The interviewer marks your thinking, not only the code.
